# ThermoSpec 🛠️

**ThermoSpec** — это веб-приложение для интеграции, нормализации и поиска данных из разнородных офлайн-каталогов инженерного оборудования.

Проект разработан для автоматизации работы инженеров в проектных бюро. Система позволяет уйти от хаотичного поиска по сотням разрозненных файлов поставщиков, собирая данные в единую локальную базу с возможностью гибкого поиска, сравнения и экспорта.

Проект полностью разработан мной: от проектирования архитектуры и модели данных до реализации клиентской и серверной частей приложения.

## 🎯 Какую задачу решает проект?

В инженерной практике каталоги оборудования часто поставляются не только в виде онлайн каталогов, но и в офлайн форматах (PDF, XLSX, DOCX) и с абсолютно разной структурой характеристик. **ThermoSpec** автоматизирует этот хаос:

1. **Умный импорт:** позволяет парсить данные из файлов, используя классические алгоритмы и ИИ, а затем применять к ним маппинг и трансформации
2. **Гибкая структура данных:** использует модель **EAV (Entity-Attribute-Value)**, что позволяет без перепроектирования БД добавлять новые категории оборудования и любые кастомные атрибуты к ним
3. **Рабочее место инженера:** позволяет искать оборудование по локальной базе, сравнивать модели между собой, группировать их в проекты и выгружать результаты в Excel для дальнейшей работы

## 💻 Функционал приложения

- **Импорт данных:** загрузка файлов (PDF, Word, Excel), извлечение технических характеристик с помощью классических алгоритмов и LLM, нормализация данных
- **Поиск и фильтрация:** полнотекстовый поиск, динамическая фильтрация по атрибутам выбранной категории оборудования
- **Панель сравнения:** сравнение характеристик нескольких моделей оборудования с подсветкой различий
- **Управление проектами:** возможность создавать проекты и добавлять туда выбранные позиции оборудования
- **Экспорт:** выгрузка сформированных списков оборудования из проектов в таблицы Excel для дальнейшей работы
- **Управление структурой каталога:** управление категориями и их атрибутами: настройка специфичных параметров (например, мощность, давление, диаметр) для каждой группы оборудования

## 🧠 Ключевые технические решения

### Гибкая модель данных на основе EAV

Система использует модель Entity-Attribute-Value, что позволяет добавлять новые категории оборудования и их атрибуты без изменения схемы базы данных

### Динамическая система поиска

Набор фильтров и структура результатов поиска формируются на основе метаданных выбранной категории оборудования

### Массовый импорт данных

Реализован механизм импорта Excel-каталогов с визуальным выбором диапазонов, маппингом колонок и пользовательскими трансформациями данных

### AI-assisted обработка данных

Система поддерживает двухэтапную обработку данных: при массовом импорте пользователь может скорректировать результаты тестового прогона модели на нескольких значениях из колонки, после чего исправления используются как few-shot примеры для обработки всей колонки целиком. При единичном импорте данных ИИ анализирует содержимое документа и предлагает значения для заполнения полей формы

### Кэширование агрегированных фильтров

Для ускорения поиска реализовано кэширование диапазонов характеристик и агрегированных фильтров

## 🏗️ Архитектура системы

![Architecture](https://github.com/joat21/ThermoSpec/blob/main/repo-images/architecture.png)

Система построена по классической клиент-серверной архитектуре и состоит из React-клиента, backend-приложения на Express, базы данных PostgreSQL и объектного хранилища для файлов.

Клиентское приложение отвечает за работу пользовательского интерфейса, поиск оборудования, управление проектами и процессы импорта данных. Backend предоставляет REST API, реализует бизнес-логику системы, взаимодействует с базой данных, файловым хранилищем и внешними LLM-сервисами для обработки каталогов.

Для хранения структурированных данных используется PostgreSQL, а загружаемые каталоги сохраняются в Yandex Object Storage через S3-совместимый API.

## 🔄 Поток обработки данных

![Workflow](https://github.com/joat21/ThermoSpec/blob/main/repo-images/workflow.png)

Система поддерживает два сценария наполнения каталога оборудования.

При массовом импорте данные из Excel-файлов сначала попадают в промежуточную область обработки, где проходят этапы преобразования, нормализации и маппинга колонок с атрибутами системы. После проверки результаты сохраняются в основное хранилище оборудования.

При ручном добавлении оборудования данные вводятся через типизированную форму и сразу сохраняются в систему без промежуточного этапа обработки.

Структура хранения определяется справочником категорий и атрибутов, построенным на основе EAV-модели. Этот же справочник используется механизмом нормализации данных и определяет правила обработки различных типов характеристик.

Сохраненные данные используются для поиска, сравнения оборудования и ведения проектов.

## 🛠️ Стек технологий

### Frontend

- **Ядро:** React 19, TypeScript, Vite
- **Интерфейс:** TailwindCSS v4, HeroUI, Lucide React, @dnd-kit
- **Управление состоянием:** Zustand, TanStack Query

### Backend

- **Ядро:** Node.js (Express 5), TypeScript
- **Хранение и управление данными:** PostgreSQL, Prisma ORM, AWS S3 SDK
- **Интеграция ИИ:** OpenAI SDK

## ⚙️ Быстрый старт

### Требования

Убедитесь, что у вас установлена **Node.js версии 20.x или выше** и запущен инстанс PostgreSQL

### Установка

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/joat21/ThermoSpec.git
   cd ThermoSpec
   
   ```
2. Установите зависимости для всего монорепозитория:

   ```bash
   npm install
   
   ```
3. Настройте переменные окружения (создайте файлы .env в /backend и /frontend на основе примеров .env.example)

### Настройка базы данных

1. Убедитесь, что в /backend/.env указана корректная строка подключения к PostgreSQL
2. Примените схему для создания структуры таблиц:

   ```bash
   npx prisma db push --schema=backend/prisma/schema.prisma
   
   ```

### Запуск в режиме разработки

Запуск фронтенда и бэкенда одной командой:

```bash
npm run dev
```

- Фронтенд будет доступен на: http://localhost:5173
- Бэкенд будет доступен на: http://localhost:8080
